# 视频审核交互 Demo

公开的 GitHub Pages 交互原型。仓库不包含测试录屏、截图、日志或其他公司素材。

打开网页后，点击「选择本地录屏」。视频通过浏览器的本地 Blob URL 播放，不上传；刷新页面后需重新选择原文件。

- 13 类模拟检测时间轨道、同步局部框选与全画面提示。
- 空格播放 / 暂停，左右键切换问题，`[` / `]` 跳转 5 秒，B 快捷提单。
- 问题点前后各 1–3 秒片段引用与预览。
- QA、验收结果、备注及本地附件；问题单保存于浏览器，可导出 JSON。
- 审核状态按文件名称、大小、修改时间区分，切换视频不会混用审核进度；这不是内容哈希身份校验。

检测类型、区间、坐标与置信度均为演示数据，不代表对所选视频的真实分析。片段为原文件时间区间引用，不生成转码文件，未对接真实 Bug 系统。

页面没有文件上传接口、外部依赖或统计脚本。CSP 禁止网络连接请求；本地截图、日志与附件使用浏览器 IndexedDB 保存，问题记录使用 localStorage 保存。清除站点数据会删除这些本地记录。

GitHub Pages 使用 main 分支仓库根目录发布。

可拖动问题轨道中的黄色播放指针或时间刻度定位；拖动时暂停，松开后恢复原先的播放状态。按 H 或「问题标注」开关可隐藏/恢复局部框选和全画面提示，右侧详情保留；全屏播放内也有标注按钮。

支持一次多选本地录屏加入视频队列，点击「下一个视频」继续审核，也可从队列下拉框返回任意视频。队列末尾可继续选择新文件；切换自动保存当前记录，每个视频的处理记录和日志分别关联。队列文件仅在本次页面打开期间保留，刷新后需重新选择文件；已有审核记录仍保留。

顶部「问题处理进度」显示当前视频已处理问题数 / 检测问题总数，确认并保存 Bug 草稿、跳过、误报均计入；手动新建问题单不增加检测问题总数。筛选类型不改变总数。

新版统一沿用报告平台的导航与配色。处理操作为「确认并提单 / 误报 / 跳过」；跳过计入处理进度，可撤销。右侧「当前帧 / 全部 Bug」集中显示检测问题和已记录的 Bug；保存后留在当前页签，恢复提单前的播放状态。全部 Bug 按当前报告（独立模式按当前队列）隔离。

快捷提单按钮与 B 键始终人工新建，标题、备注为空，默认类型为其他 / 人工发现，不会关联当前检测结果或增加其处理进度。问题卡片上的「确认并提单」才会关联该检测问题。右侧卡片显示「人工发现 / 检测确认」来源。

当前版本仅处理单个 Bug：保存后显示「已记录」，可编辑与撤销。不显示正式提交、待提交数量、复核要求。问题处理进度仅在顶部显示一处，去掉整份报告重复进度及剩余数量提示；报告列表仍同步处理进度。飞书项目批量提单留待后续接入，当前无外部提交。

确认后不切换页签；当前问题显示已确认状态，支持编辑和撤销。撤销检测确认会移除对应 Bug 并恢复待处理；撤销人工 Bug 不影响检测进度。编辑复用原提单抽屉，回填所有字段与附件，保留截图和日志；不会新增记录。移除列表的「回看片段」，抽屉内保留片段预览。

Bug 卡片仅保留「编辑 / 撤销」，移除「证据 / 附件」入口及截图、日志、附件数量摘要。提单/编辑抽屉仍保留关联证据和补充附件，已有数据不变。
